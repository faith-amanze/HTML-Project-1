Selected work

Security · LLM agent

FP-Triage

An LLM-powered tool that auto-dismisses known false-positive security alerts. It asks one question: has this exact device signed in for this exact user before? Anything unfamiliar goes to a human, and low-confidence dismissals are sent back to escalate.

99.6%of 1,070 naive flags correctly auto-dismissed
1,096 → 4first-seen devices found offline
7 / 15dismissed / escalated in a live 22-event run

Machine learning · SEO

Content Refresh Prioritization

My FlyRank internship capstone: ranking which of 30,000 underperforming SEO pages deserve a content team's limited review time. I used a client-grouped holdout split to avoid leakage, and the paper reports the model's failure modes openly.
